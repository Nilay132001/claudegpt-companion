# M6 — Jira, read-only (companion-jira proxy) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GPT can read Jira issues, run JQL searches and read issue comments, never write anything, and never see or hold the Jira credential. The self-check proves that no write-shaped tool is visible.

**Architecture:** A new MCP server, `companion-jira`, written in companiond's own TypeScript. companiond launches it per thread under its own Seatbelt profile (Node, outbound TCP 443 and DNS only, no file reads beyond its runtime, no writes, no exec). It reaches Codex through the existing relay, acceptor and sandboxed validator, exactly like `companion-readonly`; the validator gets its own tool allowlist per grant. The server exposes three fixed read tools and makes only `GET` requests to `https://<site>.atlassian.net/_edge/tenant_info` and `https://api.atlassian.com/ex/jira/<cloudId>/rest/api/3/…`. The credential (site, email, scoped API token) is kept by the SwiftUI app in its own Keychain item. The app sends it to companiond over stdio (`jira.configure`). companiond holds it in memory only and writes it to the server's fd 3 (a pipe) at spawn. It never goes into argv, env, a file, a log, Codex, a prompt or the model.

**Tech Stack:** Node ≥ 24 TypeScript (`node --test`, global `fetch`), Seatbelt (`sandbox-exec`), Codex app-server 0.166.0 (pinned), Swift 6.2 / SwiftUI on macOS 26 (Swift Testing), Security.framework `SecItem*` (generic password, one file only).

## Global Constraints

- **Jira is read-only at four layers.** (1) The token's scopes (`read:jira-work`, `read:jira-user`; the owner creates it). (2) `JiraClient` has one HTTP verb, `GET`, and builds every URL from fixed path templates. (3) The server lists exactly `JIRA_TOOL_NAMES`, and the validator, Codex's `enabled_tools` and the runtime guard allow only those. (4) The self-check fails on any tool of any server that is not allowlisted **or** whose name is write-shaped (`isWriteShapedTool`).
- **The credential never leaves memory except over two pipes.** App → companiond: the `jira.configure` params on stdio. companiond → `companion-jira`: one JSON line on fd 3, then EOF. Never argv, env, a file, a log line, an error message, a `DaemonError`, a Codex config or override, developer instructions, a tool result or a prompt. `jira.status` never returns the token. `JiraCredentials` objects serialise to a redacted form (`toJSON`).
- **Network:** only `companion-jira` (and its `--check` mode) talks to Atlassian. Its profile allows outbound `tcp *:443` minus loopback, plus the DNS socket. companiond itself makes no network call. Codex gets no Atlassian server: Atlassian's remote MCP is **not** configured anywhere.
- **Jira text is untrusted data.** Every tool result is escaped with `escapeData`, passed through `redactText`, capped, and wrapped as `<untrusted_data source="jira">…</untrusted_data>`. Developer instructions say so (spec §7.6).
- **Tests: synthetic fixtures or mocked HTTP only** (`SYNTHETIC FIXTURE` marker, site `example-synthetic.atlassian.net`, fake tokens). No test talks to a real Jira. The profile measurement (Task 3) talks only to `https://example.com`.
- **No change to Claude Desktop or Claude Code config. Never read Claude credentials, `~/.claude/sessions/*.key`, or the messaging socket.**
- **Swift `SecItem*` / `kSecClass` appear only in `app/Sources/CompanionCore/Secrets/JiraKeychain.swift`.** SourceRules keeps banning them everywhere else and checks that this file names only the service `ClaudeGPT Companion Jira`.
- **No `print`/`NSLog`/`debugPrint`/`dump(` in `app/Sources`**, and no `console.*` or stderr write that carries Jira data in companiond. companiond's stderr gets fixed short codes only.
- **Public repo hygiene:** no personal data, no `/Users/<name>/` paths, no real site names, emails or tokens; no license file. Run `bash scripts/check-repo.sh` before every commit.

```ts
// The Jira credential (owner ruling B, M6): site + email + scoped read-only API token. It lives in memory only: the
// app's Keychain item → jira.configure (stdio) → JiraService → fd 3 of companion-jira. Error messages are fixed and
// never contain the input.
export interface JiraCredentials { site: string; email: string; token: string }

export class JiraInputError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "JiraInputError";
  }
}

const SITE = /^[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?\.atlassian\.net$/;
const EMAIL = /^[^\s@\u0000-\u001f\u007f]{1,64}@[^\s@\u0000-\u001f\u007f]{1,189}$/;
const TOKEN = /^[\x21-\x7e]{16,2048}$/;
/** Jira project keys: an upper-case letter, then letters, digits or _; the number has no leading zero. */
export const ISSUE_KEY = /^[A-Z][A-Z0-9_]{0,19}-[1-9][0-9]{0,9}$/;
export const MAX_JQL = 1000;
export const MAX_RESULTS = 20;
const MAX_SECRET_BYTES = 8192;

export function normalizeSite(input: string): string {
  let s = input.trim().toLowerCase();
  if (s.startsWith("https://")) {
    s = s.slice("https://".length);
    if (s.endsWith("/")) s = s.slice(0, -1);
  }
  if (!SITE.test(s)) throw new JiraInputError("The Jira site must look like your-team.atlassian.net.");
  return s;
}

export function parseCredentials(p: { site: unknown; email: unknown; token: unknown }): JiraCredentials {
  if (typeof p.site !== "string") throw new JiraInputError("The Jira site must look like your-team.atlassian.net.");
  const site = normalizeSite(p.site);
  if (typeof p.email !== "string" || !EMAIL.test(p.email.trim())) throw new JiraInputError("The Atlassian account email does not look like an email address.");
  if (typeof p.token !== "string" || !TOKEN.test(p.token)) throw new JiraInputError("The API token must be 16 to 2048 visible characters with no spaces.");
  return { site, email: p.email.trim(), token: p.token };
}

export function encodeSecret(c: JiraCredentials): string {
  return `${JSON.stringify({ site: c.site, email: c.email, token: c.token })}\n`;
}

export function decodeSecret(raw: string): JiraCredentials {
  if (Buffer.byteLength(raw) > MAX_SECRET_BYTES) throw new JiraInputError("The Jira credential is too large.");
  let o: unknown;
  try {
    o = JSON.parse(raw.trim());
  } catch {
    throw new JiraInputError("The Jira credential could not be read.");
  }
  if (typeof o !== "object" || o === null || Array.isArray(o)) throw new JiraInputError("The Jira credential could not be read.");
  const r = o as Record<string, unknown>;
  return parseCredentials({ site: r.site, email: r.email, token: r.token });
}

export function redactedCredentials(c: JiraCredentials): { site: string; email: string; token: "<hidden>" } {
  return { site: c.site, email: c.email, token: "<hidden>" };
}

```ts
// GET-only Jira Cloud REST client for companion-jira (owner ruling B). Scoped API tokens work only through
// api.atlassian.com/ex/jira/<cloudId>; the cloudId comes from the site's public tenant_info (no token sent there).
// fetch is injected so tests never touch the network. Messages are fixed: no token, no Jira text.
import { ISSUE_KEY, MAX_JQL, MAX_RESULTS, type JiraCredentials } from "./credentials.ts";

export type FetchFn = (
  url: string,
  init: { method: "GET"; headers: Record<string, string>; redirect: "error"; signal: AbortSignal },
) => Promise<{ status: number; text(): Promise<string> }>;

export type JiraErrorKind = "auth" | "notFound" | "badRequest" | "rateLimited" | "network" | "site" | "tooLarge" | "server";
const MESSAGES: Record<JiraErrorKind, string> = {
  auth: "Jira refused the API token. Check it in Settings › Jira (it needs read:jira-work and read:jira-user).",
  notFound: "Jira found nothing there, or the token has no access to it.",
  badRequest: "Jira could not run that request. Check the issue key or the JQL.",
  rateLimited: "Jira is rate-limiting requests. Try again in a minute.",
  network: "Jira could not be reached.",
  site: "That Jira site could not be found.",
  tooLarge: "Jira's answer was too large.",
  server: "Jira had an error. Try again later.",
};

export class JiraError extends Error {
  readonly kind: JiraErrorKind;
  constructor(kind: JiraErrorKind) {
    super(MESSAGES[kind]);
    this.name = "JiraError";
    this.kind = kind;
  }
}

const MAX_BODY_CHARS = 2 * 1024 * 1024;
const CLOUD_ID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;
const ISSUE_FIELDS = "summary,status,issuetype,priority,assignee,reporter,labels,created,updated,parent,description";
const SEARCH_FIELDS = "summary,status,issuetype,assignee,updated";

export class JiraClient {
  readonly #c: JiraCredentials;
  readonly #fetch: FetchFn;
  readonly #timeoutMs: number;
  readonly #apiBase: string;
  #cloudId: string | null = null;

  constructor(c: JiraCredentials, o: { fetch?: FetchFn; timeoutMs?: number; apiBase?: string } = {}) {
    this.#c = c;
    this.#fetch = o.fetch ?? (globalThis.fetch as unknown as FetchFn);
    this.#timeoutMs = o.timeoutMs ?? 15_000;
    this.#apiBase = o.apiBase ?? "https://api.atlassian.com";
  }

  toJSON(): string {
    return "JiraClient";
  }

  // async: a bad input becomes a rejection, before any request.
  async issue(key: string): Promise<unknown> {
    checkKey(key);
    return this.#api(`/issue/${encodeURIComponent(key)}`, { fields: ISSUE_FIELDS });
  }

  async search(jql: string, max: number): Promise<unknown> {
    if (typeof jql !== "string" || jql.trim().length === 0 || jql.length > MAX_JQL) throw new JiraError("badRequest");
    checkMax(max);
    return this.#api("/search/jql", { jql, maxResults: String(max), fields: SEARCH_FIELDS });
  }

  async comments(key: string, max: number): Promise<unknown> {
    checkKey(key);
    checkMax(max);
    return this.#api(`/issue/${encodeURIComponent(key)}/comment`, { orderBy: "-created", maxResults: String(max) });
  }

  async myself(): Promise<unknown> {
    return this.#api("/myself", {});
  }

  async #api(path: string, query: Record<string, string>): Promise<unknown> {
    const cloudId = await this.#resolveCloudId();
    const q = new URLSearchParams(query).toString();
    const url = `${this.#apiBase}/ex/jira/${encodeURIComponent(cloudId)}/rest/api/3${path}${q ? `?${q}` : ""}`;
    const auth = `Basic ${Buffer.from(`${this.#c.email}:${this.#c.token}`).toString("base64")}`;
    const r = await this.#get(url, { Authorization: auth, Accept: "application/json" });
    if (r.status === 401 || r.status === 403) throw new JiraError("auth");
    if (r.status === 404) throw new JiraError("notFound");
    if (r.status === 400) throw new JiraError("badRequest");
    if (r.status === 429) throw new JiraError("rateLimited");
    if (r.status < 200 || r.status >= 300) throw new JiraError("server");
    return parseJson(r.body, "server");
  }

  async #resolveCloudId(): Promise<string> {
    if (this.#cloudId) return this.#cloudId;
    const r = await this.#get(`https://${this.#c.site}/_edge/tenant_info`, { Accept: "application/json" });
    if (r.status !== 200) throw new JiraError("site");
    const o = parseJson(r.body, "site");
    const id = typeof o === "object" && o !== null ? (o as Record<string, unknown>).cloudId : undefined;
    if (typeof id !== "string" || !CLOUD_ID.test(id)) throw new JiraError("site");
    this.#cloudId = id;
    return id;
  }

  async #get(url: string, headers: Record<string, string>): Promise<{ status: number; body: string }> {
    let res: { status: number; text(): Promise<string> };
    let body: string;
    try {
      res = await this.#fetch(url, { method: "GET", headers, redirect: "error", signal: AbortSignal.timeout(this.#timeoutMs) });
      body = await res.text();
    } catch {
      throw new JiraError("network");
    }
    if (body.length > MAX_BODY_CHARS) throw new JiraError("tooLarge");
    return { status: res.status, body };
  }
}

function checkKey(key: unknown): void {
  if (typeof key !== "string" || !ISSUE_KEY.test(key)) throw new JiraError("badRequest");
}
function checkMax(max: unknown): void {
  if (typeof max !== "number" || !Number.isInteger(max) || max < 1 || max > MAX_RESULTS) throw new JiraError("badRequest");
}
function parseJson(s: string, kind: JiraErrorKind): unknown {
  try {
    return JSON.parse(s);
  } catch {
    throw new JiraError(kind);
  }
}

```ts
// Jira JSON → plain text for the model (spec §7.4, §7.6). Everything that came from Jira is escaped like the context
// block (escapeData), redacted (best effort) and capped, then wrapped once as untrusted data.
import { escapeData } from "../context/contextBuilder.ts";
import { redactText } from "../jail/redactor.ts";

export const JIRA_TEXT_CAP = 24_000;
const DESCRIPTION_CAP = 8_000;
const COMMENT_CAP = 2_000;
const MAX_NODES = 5_000;
const MAX_DEPTH = 40;

type Json = Record<string, unknown>;
const obj = (v: unknown): Json | null => (typeof v === "object" && v !== null && !Array.isArray(v) ? (v as Json) : null);
const s = (v: unknown): string => (typeof v === "string" ? v : "");
const name = (v: unknown, fallback = ""): string => s(obj(v)?.name) || s(obj(v)?.displayName) || fallback;
const BLOCKS = new Set(["paragraph", "heading", "blockquote", "codeBlock", "listItem", "rule", "panel", "table", "tableRow", "mediaSingle", "mediaGroup"]);

export function adfToText(node: unknown, maxChars: number): string {
  let out = "";
  let nodes = 0;
  const walk = (n: unknown, depth: number, prefix: string): void => {
    if (out.length >= maxChars || depth > MAX_DEPTH || ++nodes > MAX_NODES) return;
    const o = obj(n);
    if (!o) return;
    const type = s(o.type);
    const attrs = obj(o.attrs) ?? {};
    if (type === "text") out += s(o.text);
    else if (type === "hardBreak") out += "\n";
    else if (type === "mention") out += s(attrs.text) || "@someone";
    else if (type === "emoji") out += s(attrs.shortName) || s(attrs.text);
    else if (type === "inlineCard" || type === "blockCard") out += s(attrs.url);
    else if (type === "media" || type === "mediaInline") out += "[attachment]";
    else if (type === "rule") out += "---";
    if (type === "listItem") out += `${prefix}- `;
    if (type === "codeBlock") out += "```\n";
    const kids = Array.isArray(o.content) ? o.content : [];
    for (const k of kids) walk(k, depth + 1, type === "bulletList" || type === "orderedList" ? `${prefix}  ` : prefix);
    if (type === "codeBlock") out += "\n```";
    if (BLOCKS.has(type) && !out.endsWith("\n")) out += "\n";
  };
  walk(node, 0, "");
  return out.slice(0, maxChars).replace(/\n{3,}/g, "\n\n").trim();
}

/** The one wrapper: escaped (so a payload cannot close it), redacted, capped. */
export function wrapJira(body: string): string {
  const text = escapeData(redactText(body));
  const capped = text.length > JIRA_TEXT_CAP ? `${text.slice(0, JIRA_TEXT_CAP)}\n[cut: the rest was too long]` : text;
  return `<untrusted_data source="jira">\n${capped}\n</untrusted_data>`;
}

export function formatIssue(j: unknown): string {
  const o = obj(j) ?? {};
  const f = obj(o.fields) ?? {};
  const labels = Array.isArray(f.labels) ? f.labels.filter((x) => typeof x === "string").join(", ") : "";
  const lines = [
    `${s(o.key)} · ${s(f.summary)}`,
    `Status: ${name(f.status, "?")} · Type: ${name(f.issuetype, "?")} · Priority: ${name(f.priority, "none")}`,
    `Assignee: ${name(f.assignee, "Unassigned")} · Reporter: ${name(f.reporter, "?")}`,
    `Created: ${s(f.created)} · Updated: ${s(f.updated)}`,
    ...(s(obj(f.parent)?.key) ? [`Parent: ${s(obj(f.parent)?.key)}`] : []),
    ...(labels ? [`Labels: ${labels}`] : []),
    "Description:",
    adfToText(f.description, DESCRIPTION_CAP) || "(none)",
  ];
  return wrapJira(lines.join("\n"));
}

export function formatSearch(jql: string, j: unknown): string {
  const issues = Array.isArray(obj(j)?.issues) ? (obj(j)?.issues as unknown[]) : [];
  const rows = issues.map((i) => {
    const o = obj(i) ?? {};
    const f = obj(o.fields) ?? {};
    return `${s(o.key)} · ${s(f.summary)} · ${name(f.status, "?")} · ${name(f.issuetype, "?")} · ${name(f.assignee, "Unassigned")} · updated ${s(f.updated)}`;
  });
  return wrapJira([`JQL: ${jql}`, ...(rows.length > 0 ? rows : ["No issues matched."])].join("\n"));
}

export function formatComments(key: string, j: unknown): string {
  const list = Array.isArray(obj(j)?.comments) ? (obj(j)?.comments as unknown[]) : [];
  const rows = list.map((c) => {
    const o = obj(c) ?? {};
    return `— ${name(o.author, "someone")}, ${s(o.created)}:\n${adfToText(o.body, COMMENT_CAP)}`;
  });
  return wrapJira([`Comments on ${key} (newest first):`, ...(rows.length > 0 ? rows : ["No comments."])].join("\n\n"));
}

import { JiraError } from "./client.ts";
import { ISSUE_KEY, MAX_JQL, MAX_RESULTS } from "./credentials.ts";

export const JIRA_TOOL_NAMES = ["jira_get_issue", "jira_search", "jira_get_comments"] as const;
export type JiraToolName = (typeof JIRA_TOOL_NAMES)[number];
export interface JiraApi {
  issue(key: string): Promise<unknown>;
  search(jql: string, max: number): Promise<unknown>;
  comments(key: string, max: number): Promise<unknown>;
}

const annotations = { readOnlyHint: true, destructiveHint: false, idempotentHint: true, openWorldHint: true };
const keyProp = { type: "string", pattern: ISSUE_KEY.source, description: "Issue key, for example ABC-123." };
const maxProp = { type: "integer", minimum: 1, maximum: MAX_RESULTS };
export const DEFAULT_RESULTS = 10;

export const JIRA_TOOL_DEFS = [
  {
    name: "jira_get_issue",
    description: "Read one Jira issue: summary, status, type, people, dates and description. Read-only.",
    inputSchema: { type: "object", properties: { key: keyProp }, required: ["key"], additionalProperties: false },
    annotations,
  },
  {
    name: "jira_search",
    description: `Search Jira issues with JQL. Returns up to ${MAX_RESULTS} issues (default ${DEFAULT_RESULTS}): key, summary, status, type, assignee, updated. Read-only.`,
    inputSchema: { type: "object", properties: { jql: { type: "string", minLength: 1, maxLength: MAX_JQL }, max_results: maxProp }, required: ["jql"], additionalProperties: false },
    annotations,
  },
  {
    name: "jira_get_comments",
    description: `Read the newest comments on a Jira issue (up to ${MAX_RESULTS}, default ${DEFAULT_RESULTS}). Read-only.`,
    inputSchema: { type: "object", properties: { key: keyProp, max_results: maxProp }, required: ["key"], additionalProperties: false },
    annotations,
  },
];

const WRITE_TOKENS = new Set(["create", "edit", "update", "transition", "add", "delete", "remove", "assign", "worklog", "post", "put", "patch",
  "write", "set", "move", "link", "upload", "archive", "comment", "send", "submit", "merge", "close", "resolve"]);
const READ_TOKENS = new Set(["get", "list", "read", "search", "fetch", "lookup", "status", "diff"]);

/** True for a name that looks like it changes something. A read verb (get/list/read/search…) followed by a noun is
 * not write-shaped, so jira_get_comments passes and addCommentToJiraIssue does not (spec §11, M6). */
export function isWriteShapedTool(name: string): boolean {
  const tokens = name.split(/[_\-.\s]+|(?<=[a-z0-9])(?=[A-Z])/).map((t) => t.toLowerCase()).filter((t) => t.length > 0);
  const firstRead = tokens.findIndex((t) => READ_TOKENS.has(t));
  const verbs = firstRead === -1 ? tokens : tokens.slice(0, firstRead);
  return verbs.some((t) => WRITE_TOKENS.has(t));
}

const fail = (text: string) => ({ text, isError: true });
const ARGS: Record<JiraToolName, readonly string[]> = { jira_get_issue: ["key"], jira_search: ["jql", "max_results"], jira_get_comments: ["key", "max_results"] };

export async function runJiraTool(api: JiraApi, name: string, args: Record<string, unknown>): Promise<{ text: string; isError: boolean }> {
  if (!(JIRA_TOOL_NAMES as readonly string[]).includes(name)) return fail("Unknown tool.");
  const tool = name as JiraToolName;
  if (Object.keys(args).some((k) => !ARGS[tool].includes(k))) return fail("Unexpected argument.");
  const max = args.max_results ?? DEFAULT_RESULTS;
  if (typeof max !== "number" || !Number.isInteger(max) || max < 1 || max > MAX_RESULTS) return fail(`max_results must be 1 to ${MAX_RESULTS}.`);
  try {
    if (tool === "jira_search") {
      if (typeof args.jql !== "string" || args.jql.trim() === "" || args.jql.length > MAX_JQL) return fail(`jql must be 1 to ${MAX_JQL} characters.`);
      return { text: formatSearch(args.jql, await api.search(args.jql, max)), isError: false };
    }
    if (typeof args.key !== "string" || !ISSUE_KEY.test(args.key)) return fail("key must be an issue key like ABC-123.");
    if (tool === "jira_get_issue") return { text: formatIssue(await api.issue(args.key)), isError: false };
    return { text: formatComments(args.key, await api.comments(args.key, max)), isError: false };
  } catch (e) {
    return fail(e instanceof JiraError ? e.message : "Jira could not be read.");
  }
}

```ts
// companion-jira: MCP over newline-delimited JSON-RPC on stdio (owner ruling B). Only initialize, ping, tools/list and
// tools/call; the validator in front of it allows nothing else either.
import { SUPPORTED_PROTOCOL_VERSIONS } from "../jail/mcpServer.ts";
import { JIRA_SERVER_NAME, JIRA_TOOL_DEFS, runJiraTool, type JiraApi } from "./tools.ts";

export type JiraServerState = { kind: "ready"; api: JiraApi } | { kind: "refused"; reason: string };
type Json = Record<string, unknown>;
const result = (id: unknown, r: unknown): Json => ({ jsonrpc: "2.0", id, result: r });
const rpcError = (id: unknown, code: number, message: string): Json => ({ jsonrpc: "2.0", id, error: { code, message } });
const toolReply = (id: unknown, text: string, isError: boolean): Json => result(id, { content: [{ type: "text", text }], isError });

export async function handleJiraMessage(state: JiraServerState, raw: unknown): Promise<Json | null> {
  if (typeof raw !== "object" || raw === null || Array.isArray(raw)) return rpcError(null, -32600, "Invalid Request");
  const msg = raw as Json;
  const id = msg.id;
  if (id === undefined || id === null) return null;
  if (typeof msg.method !== "string") return rpcError(id, -32600, "Invalid Request");
  const params = (typeof msg.params === "object" && msg.params !== null ? msg.params : {}) as Json;
  switch (msg.method) {
    case "initialize": {
      const asked = typeof params.protocolVersion === "string" ? params.protocolVersion : "";
      return result(id, {
        protocolVersion: SUPPORTED_PROTOCOL_VERSIONS.includes(asked) ? asked : SUPPORTED_PROTOCOL_VERSIONS[0],
        capabilities: { tools: {} },
        serverInfo: { name: JIRA_SERVER_NAME, version: "0.6.0" },
      });
    }
    case "ping":
      return result(id, {});
    case "tools/list":
      return result(id, { tools: JIRA_TOOL_DEFS });
    case "tools/call": {
      if (state.kind === "refused") return toolReply(id, state.reason, true);
      const args = params.arguments ?? {};
      if (typeof args !== "object" || args === null || Array.isArray(args)) return toolReply(id, "arguments must be an object.", true);
      const r = await runJiraTool(state.api, typeof params.name === "string" ? params.name : "", args as Json);
      return toolReply(id, r.text, r.isError);
    }
    default:
      return rpcError(id, -32601, "Method not found");
  }
}

// Entry point of companion-jira (owner ruling B). companiond spawns it under its Seatbelt profile with the credential
// as one line on fd 3 (then EOF): never argv or env. stdout = MCP (or the one --check line); stderr is unused.
import fs from "node:fs";
import { serveLines } from "../mcpStdio.ts";
import { JiraClient, JiraError } from "./client.ts";
import { decodeSecret, type JiraCredentials } from "./credentials.ts";
import { handleJiraMessage, type JiraServerState } from "./mcpServer.ts";

const NOT_SET_UP = "Jira is not set up in the companion.";

function readSecret(): JiraCredentials | null {
  try {
    const raw = fs.readFileSync(3, { encoding: "utf8" }); // reads to EOF; companiond closes its end after one line
    fs.closeSync(3);
    return decodeSecret(raw);
  } catch {
    return null;
  }
}

async function main(): Promise<void> {
  const creds = readSecret();
  if (process.argv.includes("--check")) {
    let line: Record<string, unknown>;
    if (!creds) line = { ok: false, kind: "setup" };
    else {
      try {
        await new JiraClient(creds).myself();
        line = { ok: true };
      } catch (e) {
        line = { ok: false, kind: e instanceof JiraError ? e.kind : "network" };
      }
    }
    process.stdout.write(`${JSON.stringify(line)}\n`);
    return;
  }
  const state: JiraServerState = creds ? { kind: "ready", api: new JiraClient(creds) } : { kind: "refused", reason: NOT_SET_UP };
  await serveLines(process.stdin, process.stdout, (m) => handleJiraMessage(state, m));
}

main().catch(() => {
  process.exitCode = 1;
});

```ts
// companion-jira's Seatbelt profile (owner ruling B). The validator's profile (no fork, exec of Node only, Node and
// companiond code read-only, no writes) plus outbound HTTPS: TCP 443 minus loopback, the DNS socket and the DNS /
// network mach services from Codex's measured list. No keychain or trust services: Node's TLS uses its own CA list.
import path from "node:path";
import { DNS_SOCKET, LOOPBACK_DENY, MACH_LOOKUPS } from "../codex/codexSeatbelt.ts";
import { assertReadablePrefix, SANDBOX_EXEC, sbString, type LaunchSpec } from "../launch/seatbelt.ts";
import type { Toolchain } from "../launch/toolchain.ts";

const SYSTEM_READ_SUBPATHS = ["/usr/lib", "/usr/share", "/System", "/Library/Preferences", "/private/var/db/timezone"];
const SYSTEM_READ_LITERALS = ["/", "/usr", "/private/etc/localtime", "/private/etc/hosts", "/private/etc/resolv.conf", "/private/var/run/resolv.conf",
  "/dev/null", "/dev/urandom", "/dev/random"];
const SYSTEM_META_SUBPATHS = ["/usr", "/System", "/Library", "/private/etc", "/private/var/db", "/dev"];
const SYSTEM_META_LITERALS = ["/etc", "/var", "/tmp", "/private", "/private/var", "/private/var/run"];
const KEYCHAIN_MACH = /SecurityServer|securityd|trustd/;
export const JIRA_MACH_LOOKUPS: readonly string[] = MACH_LOOKUPS.filter((n) => !KEYCHAIN_MACH.test(n));

function ancestors(p: string): string[] {
  const out: string[] = [];
  for (let c = p; c !== "/"; ) {
    c = path.dirname(c);
    out.push(c);
  }
  return out;
}
const sub = (p: string) => `(subpath ${sbString(p)})`;
const lit = (p: string) => `(literal ${sbString(p)})`;

export function buildJiraProfile(tc: Pick<Toolchain, "nodePath" | "nodeReadDirs" | "nodeReadFiles" | "metadataPaths" | "codeDir">): string {
  const reads = [...new Set([tc.codeDir, ...tc.nodeReadDirs])];
  for (const p of reads) assertReadablePrefix(p);
  const files = [...new Set(tc.nodeReadFiles)];
  const meta = [...new Set([...[...reads, ...files, tc.nodePath].flatMap(ancestors), ...files, ...tc.metadataPaths, ...SYSTEM_META_LITERALS])];
  return [
    "(version 1)",
    "(deny default)",
    '(import "system.sb")',
    `(allow process-exec ${lit(tc.nodePath)})`,
    `(allow file-read* ${[...reads, ...SYSTEM_READ_SUBPATHS].map(sub).join(" ")} ${[...files, ...SYSTEM_READ_LITERALS].map(lit).join(" ")})`,
    `(allow file-read-metadata ${[...reads, ...SYSTEM_META_SUBPATHS].map(sub).join(" ")} ${meta.map(lit).join(" ")})`,
    '(allow file-write-data (literal "/dev/null"))',
    "(allow sysctl-read)",
    '(allow network-outbound (remote tcp "*:443"))',
    LOOPBACK_DENY,
    `(allow network-outbound (remote unix-socket (path-literal ${sbString(DNS_SOCKET)})))`,
    `(allow mach-lookup ${JIRA_MACH_LOOKUPS.map((n) => `(global-name "${n}")`).join(" ")})`,
    "",
  ].join("\n");
}

export function buildJiraLaunch(tc: Toolchain, extraArgs: readonly string[] = []): LaunchSpec {
  return {
    command: SANDBOX_EXEC,
    args: ["-p", buildJiraProfile(tc), tc.nodePath, path.join(tc.codeDir, "src", "jira", "main.ts"), ...extraArgs],
    env: { PATH: "/usr/bin:/bin", OPENSSL_CONF: "/dev/null" },
    cwd: "/",
  };
}

import { isWriteShapedTool } from "../jira/tools.ts";

/** scope "thread": every server in `bound` (default: every allowlisted server) must be running and list exactly its
 * allowlist. Both scopes: every listed tool must be allowlisted and none may look like a write tool (M6). */
export function checkMcpStatus(entries: readonly unknown[], allow: ToolAllowlist, scope: "process" | "thread", bound: ReadonlySet<string> = new Set(allow.keys())): CheckResult {
  const r = empty();
  const seen = new Set<string>();
  for (const raw of entries) {
    const e = obj(raw);
    const name = typeof e?.name === "string" ? e.name : "<unnamed>";
    seen.add(name);
    const tools = Object.keys(obj(e?.tools) ?? {});
    for (const t of tools) if (isWriteShapedTool(t)) r.failures.push(`MCP tool ${name}/${t} looks like a write tool`);
    const allowed = allow.get(name);
    if (!allowed) {
      r.failures.push(`MCP server ${name} is not allowlisted`);
      continue;
    }
    for (const t of tools) if (!allowed.has(t)) r.failures.push(`MCP tool ${name}/${t} is not allowlisted`);
    if (scope === "thread" && bound.has(name)) for (const t of allowed) if (!tools.includes(t)) r.failures.push(`MCP tool ${name}/${t} is missing`);
  }
  if (scope === "thread") for (const s of bound) if (!seen.has(s)) r.failures.push(`MCP server ${s} is not running for this thread`);
  return r;
}

```ts
// The daemon's Jira state (owner ruling B): the credential in memory only, handed to CodexHost as a JiraBinding (the
// secret goes to companion-jira's fd 3 through the relay) and to the --check run. Nothing here logs, stores or
// returns the token.
import { spawn } from "node:child_process";
import type { JiraBinding } from "../codex/codexHost.ts";
import type { LaunchSpec } from "../launch/seatbelt.ts";
import type { JiraErrorKind } from "./client.ts";
import { encodeSecret, parseCredentials, redactedCredentials, type JiraCredentials } from "./credentials.ts";

export type JiraStatus = { configured: boolean; site: string | null; email: string | null };
export type JiraCheck = { ok: boolean; detail: string };
export type CheckRunner = (secret: string) => Promise<{ ok: boolean; kind?: string }>;

export const CHECK_DETAILS: Record<"ok" | "setup" | "timeout" | JiraErrorKind, string> = {
  ok: "Connected. GPT can read Jira.",
  setup: "Jira is not set up.",
  timeout: "Jira did not answer in time.",
  auth: "Jira refused the token. It needs read:jira-work and read:jira-user.",
  notFound: "Jira answered, but the token cannot see your profile.",
  badRequest: "Jira refused the request.",
  rateLimited: "Jira is rate-limiting requests. Try again in a minute.",
  network: "Jira could not be reached.",
  site: "That Jira site could not be found.",
  tooLarge: "Jira's answer was too large.",
  server: "Jira had an error. Try again later.",
};

export interface JiraServiceOptions {
  host: { setJira(j: JiraBinding | null): void };
  /** null when there is no macOS toolchain: the credential is kept, but no thread gets Jira. */
  binding: ((secret: string) => JiraBinding) | null;
  runCheck: CheckRunner | null;
}

export class JiraService {
  #o: JiraServiceOptions;
  #creds: JiraCredentials | null = null;

  constructor(o: JiraServiceOptions) {
    this.#o = o;
  }

  toJSON(): unknown {
    return this.#creds ? redactedCredentials(this.#creds) : null;
  }

  status(): JiraStatus {
    return this.#creds ? { configured: true, site: this.#creds.site, email: this.#creds.email } : { configured: false, site: null, email: null };
  }

  configure(p: { site: unknown; email: unknown; token: unknown }): JiraStatus {
    const c = parseCredentials(p); // throws JiraInputError before anything changes
    this.#creds = c;
    this.#o.host.setJira(this.#o.binding ? this.#o.binding(encodeSecret(c)) : null);
    return this.status();
  }

  clear(): JiraStatus {
    this.#creds = null;
    this.#o.host.setJira(null);
    return this.status();
  }

  async check(): Promise<JiraCheck> {
    if (!this.#creds || !this.#o.runCheck) return { ok: false, detail: CHECK_DETAILS.setup };
    try {
      const r = await this.#o.runCheck(encodeSecret(this.#creds));
      if (r.ok) return { ok: true, detail: CHECK_DETAILS.ok };
      const kind = r.kind && Object.hasOwn(CHECK_DETAILS, r.kind) && r.kind !== "ok" ? (r.kind as keyof typeof CHECK_DETAILS) : "network";
      return { ok: false, detail: CHECK_DETAILS[kind] };
    } catch {
      return { ok: false, detail: CHECK_DETAILS.network };
    }
  }
}

/** Runs `companion-jira --check` under its profile with the secret on fd 3; reads one line (≤ 4 KB) from stdout. */
export function spawnCheck(launch: LaunchSpec, secret: string, timeoutMs = 20_000): Promise<{ ok: boolean; kind?: string }> {
  return new Promise((resolve) => {
    let done = false;
    let out = "";
    const p = spawn(launch.command, launch.args, { env: launch.env, cwd: launch.cwd, stdio: ["ignore", "pipe", "ignore", "pipe"] });
    const finish = (r: { ok: boolean; kind?: string }) => {
      if (done) return;
      done = true;
      clearTimeout(timer);
      if (p.exitCode === null && p.pid !== undefined) p.kill("SIGKILL");
      resolve(r);
    };
    const timer = setTimeout(() => finish({ ok: false, kind: "timeout" }), timeoutMs);
    p.on("error", () => finish({ ok: false, kind: "network" }));
    const fd3 = p.stdio[3] as import("node:stream").Writable | null;
    fd3?.on("error", () => {});
    fd3?.end(secret);
    p.stdout?.on("data", (c: Buffer) => {
      out += c.toString("utf8");
      if (out.length > 4096) finish({ ok: false, kind: "network" });
    });
    p.on("exit", () => {
      try {
        const o = JSON.parse(out.trim()) as { ok?: unknown; kind?: unknown };
        finish({ ok: o.ok === true, kind: typeof o.kind === "string" ? o.kind : undefined });
      } catch {
        finish({ ok: false, kind: "network" });
      }
    });
  });
}

```swift
import Foundation
import Security

/// The Jira credential (owner ruling B, M6). The token never leaves this struct except into the app's own Keychain
/// item and the jira.configure call to companiond.
public struct JiraCredentials: Codable, Sendable, Equatable, CustomStringConvertible, CustomDebugStringConvertible {
    public let site: String
    public let email: String
    public let token: String
    public init(site: String, email: String, token: String) {
        self.site = site
        self.email = email
        self.token = token
    }
    public var description: String { "JiraCredentials(site: \(site), email: \(email), token: <hidden>)" }
    public var debugDescription: String { description }
}

public enum KeychainError: Error, Equatable { case status(OSStatus), badData }

public protocol JiraSecretStore: Sendable {
    func load() throws -> JiraCredentials?
    func save(_ c: JiraCredentials) throws
    func delete() throws
}

/// Nothing stored (tests, and before the owner sets Jira up).
public struct NoJiraStore: JiraSecretStore {
    public init() {}
    public func load() throws -> JiraCredentials? { nil }
    public func save(_ c: JiraCredentials) throws {}
    public func delete() throws {}
}

/// One generic-password item that belongs to this app only: service "ClaudeGPT Companion Jira", account "jira".
/// It never reads, writes or deletes any other item.
public struct KeychainJiraStore: JiraSecretStore {
    public static let service = "ClaudeGPT Companion Jira"
    let service: String
    let account = "jira"
    public init(service: String = KeychainJiraStore.service) { self.service = service }

    private var base: [String: Any] {
        [kSecClass as String: kSecClassGenericPassword, kSecAttrService as String: service, kSecAttrAccount as String: account]
    }

    public func load() throws -> JiraCredentials? {
        var q = base
        q[kSecReturnData as String] = true
        q[kSecMatchLimit as String] = kSecMatchLimitOne
        var out: CFTypeRef?
        let s = SecItemCopyMatching(q as CFDictionary, &out)
        if s == errSecItemNotFound { return nil }
        guard s == errSecSuccess else { throw KeychainError.status(s) }
        guard let data = out as? Data, let c = try? JSONDecoder().decode(JiraCredentials.self, from: data) else { throw KeychainError.badData }
        return c
    }

    public func save(_ c: JiraCredentials) throws {
        let data = try JSONEncoder().encode(c)
        let update = SecItemUpdate(base as CFDictionary, [kSecValueData as String: data] as CFDictionary)
        if update == errSecSuccess { return }
        guard update == errSecItemNotFound else { throw KeychainError.status(update) }
        var add = base
        add[kSecValueData as String] = data
        add[kSecAttrAccessible as String] = kSecAttrAccessibleWhenUnlockedThisDeviceOnly
        add[kSecAttrLabel as String] = "ClaudeGPT Companion — Jira (read-only)"
        let s = SecItemAdd(add as CFDictionary, nil)
        guard s == errSecSuccess else { throw KeychainError.status(s) }
    }

    public func delete() throws {
        let s = SecItemDelete(base as CFDictionary)
        guard s == errSecSuccess || s == errSecItemNotFound else { throw KeychainError.status(s) }
    }
}
```

import Foundation

/// Jira settings (owner ruling B). The Keychain item is the only place the token is kept. companiond gets it at
/// every start and keeps it in memory. Errors show fixed texts, never the token.
extension AppModel {
    func loadJira(_ api: any DaemonAPI) async {
        do {
            if let c = try jiraStore.load() {
                jira = try await api.jiraConfigure(c)
            } else {
                jira = try await api.jiraStatus()
            }
        } catch let e as DaemonError {
            jira = try? await api.jiraStatus()
            jiraNote = e.message
        } catch {
            jira = try? await api.jiraStatus()
            jiraNote = "The Jira token could not be read from the Keychain."
        }
    }

    public func saveJira(site: String, email: String, token: String) async {
        guard let api = currentAPI else { return }
        let c = JiraCredentials(site: site.trimmingCharacters(in: .whitespacesAndNewlines), email: email.trimmingCharacters(in: .whitespacesAndNewlines), token: token)
        do {
            jira = try await api.jiraConfigure(c)
        } catch let e as DaemonError {
            jiraNote = e.message
            return
        } catch {
            jiraNote = "Jira could not be set up."
            return
        }
        do {
            try jiraStore.save(c)
            jiraNote = "Saved. Use Test connection to check it."
        } catch {
            jira = try? await api.jiraClear()
            jiraNote = "The token could not be saved in the Keychain, so Jira stays off."
        }
    }

    public func removeJira() async {
        var failed = false
        do { try jiraStore.delete() } catch { failed = true }
        if let api = currentAPI { jira = try? await api.jiraClear() }
        jiraNote = failed ? "The Keychain item could not be removed." : "Jira removed."
    }

    public func checkJira() async {
        guard let api = currentAPI else { return }
        jiraNote = "Checking…"
        do { jiraNote = try await api.jiraCheck().detail } catch let e as DaemonError { jiraNote = e.message } catch { jiraNote = "Jira could not be checked." }
    }
}
