# M8 sidebar visual design

Companion to `docs/superpowers/plans/2026-11-05-m8-ui-redesign.md` (Tasks 6 and 7). The plan's Rulings R6–R9 apply.

Revised after the owner's review of the first M8 build ("two boxes", overlapping tags and file names): the
desktop-style rulings D1–D9 below replace the header, status line, composer, turn and empty-state details of the
first version. The owner's panel is 449 pt wide; every row must hold at 280–640 pt with long titles, repository
names, branches and paths.

## Audience

- **Who:** one developer (the owner) running Claude Code Desktop, fluent in both tools, reading code all day.
- **Context stress:** glancing sideways mid-task; the panel is 280–640 pt wide (the owner uses 449) next to Claude's window; light and dark; real titles, repo names, worktree branches and paths are long.
- **Job:** ask GPT a second opinion on what Claude is doing, see exactly what GPT was given, and lift the answer (or a code block) into Claude or an editor.
- **Success:** select or copy anything in one move; know at a glance what was sent; get back to an earlier chat after a relaunch.

## Direction

The calm single surface of a desktop AI chat app: one continuous canvas on the window background, plain answer text, one soft user bubble, one composer that carries its own controls. System typography and semantic colours; the accent only on the primary action and links. Generic patterns only: no third-party branding, logos, brand colours or fonts.

**D1 One surface, fewer boxes.** The only containers are the question bubble, code blocks and the composer. No glass capsule around the titlebar buttons, no filled card around Context sent, no filled status rows in the chat. The header and the composer sit on the window background, each fading into the chat over 16 pt (`EdgeBacking`), so text scrolling under them never shows around the composer or ends in a hard cut.

**D3 No overlap at 280–640 pt.** Every control row is one line (`lineLimit(1)`): `.middle` truncation for paths, `.tail` for titles, explicit `layoutPriority` so controls never cover text, and `ViewThatFits` to drop to compact labels instead of overlapping. The branch is never inline in the composer row.

Anti-references: the v0.7.0 panel (stacked raw text rows, full-path banner, plain bordered field); the first M8 build (glass capsule, glass-on-glass composer, filled context card, a "GPT" label row on every answer); chat-app bubbles on both sides; purple gradients; pill clusters.

## Tokens (`Views/Design.swift`)

| Token | Value | Use |
|---|---|---|
| `Space.xs/s/m/l/xl` | 4 / 8 / 12 / 16 / 24 pt | all padding and stack spacing |
| `Radius.bubble` | 16 | question bubble |
| `Radius.code` | 8 | code block |
| `Radius.composer` | 16 | composer field |
| `Fill.bubble` | `.primary` at 7% | question bubble (neutral, light and dark) |
| `Fill.composer` | white (light); window background + 6% white, opaque (dark) | composer field |
| `Fill.hairline` | `.primary` at 12% | composer and code borders (0.5 pt), context list rule (2 pt) |
| `bodyLineSpacing` | 3 | answer prose and question |
| `turnGap` | 18 | between turns (measured from the answer's actions row) |
| `Motion.quick` | 0.12 s, `.snappy` | icon swaps, copied ticks, hover |
| `Motion.standard` | 0.18 s, `.smooth` | disclosure, status line |
| `Motion.enter` | 0.24 s, `.smooth` | new message entrance (opacity + 6 pt rise) |
| exits | 0.7 × entrance | removing rows |

Reduce Motion: no offsets, opacity only; typing dots static.

## Type

| Role | Style |
|---|---|
| Session title | `.headline` |
| Chips, metadata, timestamps | `.caption` / `.caption2`, `.secondary` |
| Question and answer | `.body` |
| Answer headings | `.title3.weight(.semibold)` (h1/h2), `.headline` (h3+) |
| Code | `.system(.callout, design: .monospaced)` |
| Empty-state title | `.title3.weight(.semibold)` |

## Layout (top → bottom)

1. **Header** (D2: identity only). Row 1, beside the traffic lights: plain borderless icon buttons in `.secondary`, no container: History (`clock.arrow.circlepath`), New chat (`square.and.pencil`, ⌘K), More (`ellipsis`: Refresh, Follow/Keep session, Explain Claude's last message, Copy conversation, Copy with context, Settings…). Row 2: status dot + session title (`.headline`, `.tail`, opens the session picker; chevron) and one secondary caption line (follow state, `.tail`). The repository and the context mode are not in the header.
2. **Status line** (D8, only when something needs attention): one borderless row on the window background, tinted symbol + one-line text + optional action + `1/3` pager + ✕. Click expands to the full text.
3. **Content**: gate state, empty state, chat, or past chat.
4. **Composer** (D7): one rounded field (radius 16) with a 0.5 pt hairline border and a soft shadow (black 6%, radius 8, y 2), 12 pt from the edges, on the window background: no glass, no double outline. Input on top (1–8 lines, "Ask GPT about this session"); below it the control row (D2): `[folder repo ▾] [Context: Ask ▾] … [Explain] [mic] [send]`.
   - **Repo menu**: folder symbol + repository name; tooltip and menu carry the full path, the branch and "read-only"; the menu offers Copy Repository Path. The accessibility label is "Repository: name · branch, read-only".
   - **Context menu**: the three modes with subtitles (choosing Automatic still asks for confirmation), then "What GPT Can See…" (the eye popover, also reachable from the empty state).
   - Fitting (D3): `ViewThatFits` tries the full labels, then the repository name truncated (ideal 120 pt) with "Context: Ask", then "Ask" / "Auto" / "Off". The trailing buttons are `fixedSize`; the controls take only what they leave.
   - Send is a 28 pt accent circle (`arrow.up`), a stop button (`stop.fill`) while answering. Return sends, ⇧/⌥ Return inserts a newline, ⌘↩ sends.

## Turn

- Question (D4): soft neutral bubble (`Fill.bubble`, radius 16), trailing, at most 80% of the column (`TrailingFraction` layout), `.body`, selectable, context menu Copy.
- Under it, trailing (D5): **Context sent** as one quiet caption line in `.secondary` — "7 context items sent ›" / "Question only" / "Question only · Context off" (the size, "Context sent · 7 items · 3.1 KB", is in the tooltip and the accessibility label). Expanded, full width: the items as a list with a 2 pt hairline leading rule, no fill. Each item: label in caption secondary (+ "2 masked" in orange caption2); prose in `.body`; commands and failure output in callout mono; edited files and folder moves as one line of file name (callout mono, primary) + parent folder (caption mono, secondary, `.middle`), the full path in the tooltip and selectable in the raw block. Long text: 6 lines, then "Show more". Notes in caption secondary. "Copy Context" and "Raw Block" are small borderless caption buttons; the raw block is the exact `<untrusted_data>` text in a code block.
- Answer (D4): plain full-width text, no bubble and no "GPT" label row. Prose is one selectable `Text` per run of non-code blocks, line spacing 3, block gaps 10 pt.
- Code blocks (D6): the one deliberate box inside answers. Hairline border, faint fill (`.primary` 3.5%), radius 8, a small header (language in caption mono secondary + borderless Copy with a "Copied" tick for 1.2 s), highlighted selectable mono that soft-wraps.
- Answer actions (D4): one compact row (22 pt) directly under the answer: Copy ▾ (click copies Markdown; menu: Copy as Markdown, Copy as Plain Text, Read Aloud), Read aloud / Pause, Stop reading, a "Speaking" badge while reading, and the time in tertiary caption. Always visible for the latest answer; on hover for older ones (opacity only, so hovering never moves text, and the actions stay reachable by keyboard and VoiceOver).
- Streaming: before the first delta, three pulsing dots ("GPT is thinking"); with text, a 2 pt accent caret after the last run is not needed — the composer's stop button and the "Answering…" caption carry the state. Tool activity: `doc.text.magnifyingglass` + "Reading the repository…" caption with a small spinner.
- Failure: borderless, orange `exclamationmark.triangle.fill` + reason + borderless "Send Again" (when retryable). Interrupted: secondary "Stopped".

## States

| State | Visual |
|---|---|
| Connecting / host starting | centered `ProgressView` + title, secondary sentence |
| Daemon down | `bolt.horizontal.circle` red, "companiond isn't running", reason, **Restart companiond** |
| Host failed | `exclamationmark.triangle` orange, "Chat is off", reason, **Try again** |
| Security stop | `lock.trianglebadge.exclamationmark` red, unchanged wording, **I've read this — acknowledge and restart** |
| Signed out | `person.crop.circle.badge.questionmark`, "Sign in with ChatGPT", one sentence, **Sign in with ChatGPT** (prominent) |
| Auth error / unsupported | as signed out with the reason and Retry |
| No session | `rectangle.on.rectangle.slash`, "No Claude session", "Open Claude Code Desktop and select a session.", **Refresh** |
| Empty chat | `bubble.left.and.text.bubble.right` in accent hierarchical, "Ask GPT about this session", "GPT sees what you allow and can read this repository, read-only.", four suggestions as plain rows (leading accent symbol, callout text that wraps; no box at rest, a soft fill on hover and press): Explain Claude's last message · Review Claude's latest change for bugs · What is Claude stuck on? · Summarize this session so far (context-dependent ones hidden in Off) |
| Past chat | borderless row under the header: `clock` "Past chat · read-only" + date + **Back to Current Chat**; composer replaced by that row's action |
| History | popover from the History button, 340×440: search field, sections Today / Earlier, rows (title, first question in secondary, `N turns · 2 h ago`, current marked with a dot), row context menu Open / Copy chat / Delete…, footer "Clear all history…" |

## Accessibility

Every icon button has `accessibilityLabel` and `.help`. A question reads "You asked: …", an answer "GPT answered: …" with actions exposed as accessibility actions (Copy, Copy as plain text, Read aloud). Status dot has a text label. The repository menu reads "Repository: name · branch, read-only"; the context line reads the full "Context sent · N items · size". Contrast relies on semantic colours; the neutral bubble fill keeps question text `.primary`.

## Verification

DEBUG demo knobs: `COMPANION_DEMO_WIDTH=<pt>` sizes the panel before the first layout; `COMPANION_DEMO_LONG=1` uses long synthetic title, repository, branch and paths. Shoot chat, context, empty, status and history at 300, 360, 449 and 600 pt with LONG=1, light and dark: nothing may overlap, clip mid-glyph, or sit boxed in a box.
