# M8 sidebar visual design

Companion to `docs/superpowers/plans/2026-11-05-m8-ui-redesign.md` (Tasks 6 and 7). The plan's Rulings R6–R9 apply.

## Audience

- **Who:** one developer (the owner) running Claude Code Desktop, fluent in both tools, reading code all day.
- **Context stress:** glancing sideways mid-task; the panel is 300–420 pt wide next to Claude's window; light and dark.
- **Job:** ask GPT a second opinion on what Claude is doing, see exactly what GPT was given, and lift the answer (or a code block) into Claude or an editor.
- **Success:** select or copy anything in one move; know at a glance what was sent; get back to an earlier chat after a relaunch.

## Direction

Calm first-party utility, in the family of Xcode's assistant sidebar and Notes: system typography, semantic colours, the app accent only on the primary action, Liquid Glass only on the navigation layer. Anti-references: the v0.7.0 panel (stacked raw text rows, full-path banner, plain bordered field), chat-app bubbles on both sides, purple gradients, pill clusters.

## Tokens (`Views/Design.swift`)

| Token | Value | Use |
|---|---|---|
| `Space.xs/s/m/l/xl` | 4 / 8 / 12 / 16 / 24 pt | all padding and stack spacing |
| `Radius.chip` | 7 | chips, code header buttons |
| `Radius.bubble` | 14 | question bubble, code block |
| `Radius.composer` | 18 | floating composer glass |
| `Motion.quick` | 0.12 s, `.snappy` | icon swaps, copied ticks, hover |
| `Motion.standard` | 0.18 s, `.smooth` | disclosure, status line |
| `Motion.enter` | 0.24 s, `.smooth` | new message entrance (opacity + 6 pt rise) |
| exits | 0.7 × entrance | removing rows |

Reduce Motion: no offsets, opacity only; typing dots static.

## Type

| Role | Style |
|---|---|
| Session title | `.headline` |
| Chips, metadata, timestamps | `.caption` / `.caption2`, `.secondary` |
| Question and answer | `.body` |
| Answer headings | `.title3.weight(.semibold)` (h1/h2), `.headline` (h3+) |
| Code | `.system(.callout, design: .monospaced)` |
| Empty-state title | `.title3.weight(.semibold)` |

## Layout (top → bottom)

1. **Header** (glass bar, hard scroll-edge effect below it). Row 1: status dot + session title as a menu-style button (opens the session picker popover; chevron), then icon buttons History (`clock.arrow.circlepath`), New chat (`square.and.pencil`, ⌘K), More (`ellipsis.circle`: Refresh ⌘R, Pin/Unpin, Copy conversation ⌘⇧C, Settings…). Row 2: repo chip (`folder.fill` tinted, `acme-widgets`, `·`, branch in secondary, `lock.fill` caption2) with `.help(full path)`; trailing context mode chip (`Context · Ask ▾`) as a borderless `Menu`.
2. **Status line** (only when something needs attention): one 28 pt row, tinted symbol + one-line text + optional action + `1/3` pager + ✕. Background `.quaternary` fill at 50%, radius 8, inset 12 pt. Click expands to the full text.
3. **Content**: gate state, empty state, chat, or past chat.
4. **Composer** (floating glass, radius 18, 10 pt inset from the edges): multi-line field (1–8 lines), placeholder "Ask GPT about this session", leading context hint row above the field in caption ("Context: Ask — you'll check before anything is sent" / "Off — only your question and the repo" / "Automatic — new session context, redacted"), trailing mic and a 28 pt circular send button (accent, `arrow.up`) that becomes a stop button (`stop.fill`) while answering. Return sends, ⇧/⌥ Return inserts a newline, ⌘↩ sends.

## Turn

- Question: trailing-aligned bubble, max 85% width, `Color.accentColor.opacity(0.12)` fill, radius 14, `.body`, selectable, context menu Copy.
- Under it, leading: **Context sent** disclosure row — `doc.text.magnifyingglass` + "Context sent · 6 items · 3.1 KB" (or "No session context · Off" / "Context: question only"), chevron rotates. Expanded: a rounded `.quaternary` container listing each item (label in caption semibold, "2 masked" in orange caption2, text in mono caption, selectable, 6 lines with "Show more"), notes in caption secondary, and a row "Copy context" / "Show raw block" (raw = the exact `<untrusted_data>` block in mono, selectable).
- Answer: full width, no bubble. A small leading label row: `sparkle` symbol + "GPT" caption semibold + time. Prose is one selectable `Text` per run of non-code blocks; code blocks are cards (header: language in caption mono secondary + Copy button with "Copied" tick for 1.2 s; body: highlighted mono, horizontal scroll, selectable).
- Answer actions (visible on hover, always in VoiceOver and the context menu): Copy (menu: Copy as Markdown, Copy as plain text), Read aloud / Pause, Stop reading.
- Streaming: before the first delta, three pulsing dots ("GPT is thinking"); with text, a 2 pt accent caret after the last run is not needed — the composer's stop button and the "Answering…" caption carry the state. Tool activity: `doc.text.magnifyingglass` + "Reading the repository…" caption with a small spinner.
- Failure: orange `exclamationmark.triangle.fill` + reason + "Send again" button (when retryable). Interrupted: secondary "Stopped".

## States

| State | Visual |
|---|---|
| Connecting / host starting | centered `ProgressView` + title, secondary sentence |
| Daemon down | `bolt.horizontal.circle` red, "companiond isn't running", reason, **Restart companiond** |
| Host failed | `exclamationmark.triangle` orange, "Chat is off", reason, **Try again** |
| Security stop | `lock.trianglebadge.exclamationmark` red, unchanged wording, **I've read this — acknowledge and restart** |
| Signed out | `person.crop.circle.badge.questionmark`, "Sign in with ChatGPT", one sentence, **Sign in with ChatGPT** (prominent) |
| Auth error / unsupported | as signed out with the reason and Retry |
| No session | `rectangle.on.rectangle.slash`, "No Claude session", "Open Claude Code Desktop and select a session.", **Refresh** |
| Empty chat | `bubble.left.and.text.bubble.right` in accent hierarchical, "Ask GPT about this session", "GPT sees what you allow and can read this repository, read-only.", four suggestion buttons (bordered, full width, leading symbol): Explain Claude's last message · Review Claude's latest change for bugs · What is Claude stuck on? · Summarize this session so far (context-dependent ones hidden in Off) |
| Past chat | slim bar under the header: `clock` "Past chat · <date> · read-only" + **Back to current chat**; composer replaced by that bar's action |
| History | popover from the History button, 340×440: search field, sections Today / Earlier, rows (title, first question in secondary, `N turns · 2 h ago`, current marked with a dot), row context menu Open / Copy chat / Delete…, footer "Clear all history…" |

## Accessibility

Every icon button has `accessibilityLabel` and `.help`. A question reads "You asked: …", an answer "GPT answered: …" with actions exposed as accessibility actions (Copy, Copy as plain text, Read aloud). Status dot has a text label. Contrast relies on semantic colours; the accent fill behind questions keeps text `.primary`.
